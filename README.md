# keltime personal website v3.5
This is version 3.5 of Ellie's personal website, hosted on nekoweb.org. 
[Visit keltime](https://keltime.nekoweb.org)

## Overview
keltime.nekoweb.org is a personal website built by Ellie made for personal use on the indie web. This project was 
written in pure HTML, CSS, and JS with the help of npm and 11ty. 

<img width="1917" height="982" alt="image" src="https://github.com/user-attachments/assets/1c87e524-6494-473d-9da4-abdabfd5f4bb" />

## Featured Pages
- About me: self explanatory
- Music: a page for album reviews
- Shrines: pages created in tribute for a certain thing
- Blog: a blog page generated with 11ty 
- Trinkets: documenting my favorite items/daily carry
- Diary: other little things
- Listography: a dupe listography for storing lists 
- Links: linking to other websites and groups- the indie web is a social community!

## Optimizations
With the introduction of v3, clutter from the previous version has been cleared, leading to a cleaner feel 
and experience. Code in the HTML and CSS have been cleaned up. Javascript files have been merged and cleaned 
to keep things concise. 

With the introduction of v3.5, 11ty has been introduced to create a whole separate blog page. Using 11ty, blog 
posts generate and load faster.
